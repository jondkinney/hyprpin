# Marketplace artwork

The repository-root `preview.png` is the landing page style promotional image
used by the README and marketplace. The [marketplace development guide](https://plugins.omarchy.org/develop.html)
documents the root `preview.png` convention. No manifest field is needed.

The artwork illustrates Hyprpin's behavior; it is not a screenshot of the
plugin's interface. The previous preview is preserved unchanged as
[settings-panel.jpg](settings-panel.jpg).

Generated on 2026-09-05 using the built-in image generation tool. The original
PNG is included without resizing or recompression: 1672 × 941 pixels.
